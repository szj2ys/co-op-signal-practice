A rehearsal before the puzzle

Co-op Signal Practice

Agree on a code. Send one item without speaking. Check that your partner received the same item before you use the code in a game.

Unofficial, independent practice tool. It does not connect to Big Walk or any other game, read game data, or solve a puzzle. Use one device together; this is not an online multiplayer session.

1Agree on the setup

A whole number from 2 to 256. Give the items a shared order, starting at 1.

Changes apply only when you choose Apply setup. Applying a setup clears the current turn.

Before the first turn

  1. Agree which side counting starts from and what each gesture means.
  2. For binary signals, agree on one signal for Yes and another for No. Send them from left to right.
  3. Agree on a distinct stop/restart signal. Test visibility and countability at the distance you will use.

Gesture names here are rehearsal labels. Choose actions both players can actually perform and distinguish in their game.

2Send an item

The receiver looks away. Draw a target, reveal the sender card, and send its code. Then hide the card before passing the device back.

No target yet. Draw one when both players are ready.

For the sender only

    3Read it back

    The receiver enters the item number they understood and repeats that number back to the sender. A match checks the code; it cannot check whether a gesture was visible in the game.

    Keep the same code

    If the answer does not match, repeat the same target after checking your starting direction and signal meanings. Swap roles when ready. There is no timer or score to chase.
