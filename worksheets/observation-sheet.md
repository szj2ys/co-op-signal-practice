## Isolate one uncertainty

Tick the first question you can answer:

- [ ] Were both people using the same ordered set of choices?
- [ ] Did both interpret left/right from the same viewpoint?
- [ ] Was the signal distinguishable at that distance?
- [ ] Was there a clear boundary between messages?
- [ ] Was the readback received before anyone acted?
- [ ] Was a stopped exchange treated as cancelled by both people?
- [ ] The cause remains unknown.
